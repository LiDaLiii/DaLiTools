# DaLiTools（大力工具）

> 一个由个人独立开发和维护的项目。

## 📌 关于本项目

这是一个个人兴趣驱动的独立开发项目，主要用于个人学习、技术研究及小范围兴趣交流。

项目的开发初衷是分享自己的想法、技术实践和开发成果，希望能够与志同道合的人交流、共同进步。

**请尊重个人开发者的劳动成果。**

本项目并非商业开源项目，公开展示不代表授权他人自由使用、复制、修改或商业化。

DaLiTools 是一个 Windows 桌面工具箱：单个安装包，装上就能用，功能以卡片形式摆在工作区里。
目前包含卡片窗、音乐、翻译、桌面角色、老板键、简洁窗口等模块。

## 下载

去 [Releases](https://github.com/LiDaLiii/DaLiTools/releases) 下最新版，只提供编译后的安装包。

- `DaLiTools_x.y.z_x64-setup.exe`：安装版，装完直接双击用。
- 遇到问题、想加功能：开一个 [Issue](https://github.com/LiDaLiii/DaLiTools/issues)
- 发版记录见 [CHANGELOG.md](CHANGELOG.md)

## 系统要求

- Windows 10 / Windows 11（64 位）
- WebView2 Runtime（Windows 11 自带；Windows 10 如果提示缺，装一次 [WebView2](https://developer.microsoft.com/microsoft-edge/webview2/)）
- 不需要装 .NET、Node、Rust 之类的东西

## 更新

程序会自己检查更新（设置 → 关于 里也能手动查）。新版从本仓的 Releases 下载，安装包带签名校验，校验不过的不会装。
